I picked this GIF because it is the first one that comes to mind when I think about coding. Learning code feels like learning a completely new language to me. Sometimes things do not make sense until I actually try them myself and see how they work. When I come across something in coding that has me confused, this Nick Young GIF is basically the face I feel like I make. With how crazy the world can be and how people are always doing different things for attention, I honestly find myself making this same face outside of coding too. This has been one of my go-to GIFs for a few years now, so it felt like the perfect one to use for this assignment.
