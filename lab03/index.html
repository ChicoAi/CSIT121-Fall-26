Additional Lessons Learned

In the current lab 3, I have been learning the foundation of styling my webpage using CSS. CSS is a language used to define the style of a webpage. There are three ways to add CSS to a webpage. The most commonly used method is to link an external CSS file to the HTML document. The other two methods are internal and inline CSS. These three methods will allow you to customize the look and feel of your webpage to your liking.
One specific challenge I faced with CSS was being tasked with certain styling features using the selectors. Identifying the correct selector to use and remembering the correct symbol for each selector was a bit challenging. Learning how to group selectors together seems like it would be very useful in the future. Referring back to CSS Selectors has been a big help when I get stuck. One helpful tip I have been using is hash symbol (#) for ID, because every ID usually have a number. Class would use a period (.) because it is a character of something. The element selector would be just the name of the element.
