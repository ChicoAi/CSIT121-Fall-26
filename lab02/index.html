My first webpage! Learning how to create a webpage from scratch is just like the book states. Essentially, it feels like I am learning another language. Learning the structure of it seems fairly easy. What may take some getting used to is nesting the attributes. Reading the first nested attribute I saw in the text made me reread it a few times to grasp what was actually going on. Overall, this is an exciting journey, and I can’t wait for all the challenges ahead.

What I Learned

  1. All HTML documents should start with !DOCTYPE declaration
  2. HTML elements are coded as a pair of tags
  3. Attributes define a setting for a HTML tag.
